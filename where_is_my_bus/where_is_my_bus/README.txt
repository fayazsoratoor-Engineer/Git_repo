WHERE IS MY BUS?  |  Prototype v1

WHAT IS INCLUDED
index.html: a responsive bus tracking demo that runs in a modern browser.

FEATURES
1. Search sample village and town routes.
2. Select one of three illustrative routes.
3. View route stops and estimated arrival times.
4. See an animated bus icon on a schematic map.
5. Mobile friendly layout.

HOW TO RUN ON WINDOWS
1. Download and extract the project ZIP.
2. Open the where_is_my_bus folder.
3. Double click index.html.
4. It opens in Chrome, Edge, or Firefox. No installation is required.

IMPORTANT LIMITATION
This is a frontend prototype. The routes, ETAs, and moving bus are simulated demo data. The map is illustrative, not a verified geographic map. It is NOT connected to KSRTC and does NOT show real buses. Real-time tracking requires a legitimate live GPS feed or a GPS device/app used by the bus operator, plus a backend service to receive and share locations. Do not present simulated data as real arrival information.
